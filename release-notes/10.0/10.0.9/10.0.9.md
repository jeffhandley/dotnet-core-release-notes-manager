# .NET 10.0.9

## Notable Changes (draft — non-security)

> Draft pre-authored from constituent-repo fixes merged in the `2026-05-12..2026-06-28` window. Security/CVE content, the Downloads table, and the package list are added separately by humans and release tooling.

### Runtime

#### JIT / CodeGen

- Fixed assertions generated by `optCreateJumpTableImpliedAssertions` ([dotnet/runtime #127003](https://github.com/dotnet/runtime/pull/127003)).
- Fixed a bug in `GenTree::Equals` ([dotnet/runtime #128724](https://github.com/dotnet/runtime/pull/128724)).
- Fixed CEA cloning when an enumerator local is reassigned from an untracked source ([dotnet/runtime #128909](https://github.com/dotnet/runtime/pull/128909)).
- Fixed `optOptimizeBoolsCondBlock` incorrectly processing unsigned inputs ([dotnet/runtime #128960](https://github.com/dotnet/runtime/pull/128960)).

#### GC

- Redid the GC heap-size fix for heavily pinning scenarios ([dotnet/runtime #127573](https://github.com/dotnet/runtime/pull/127573)).
- Fixed `heap_segment_used` watermark after compaction ([dotnet/runtime #128342](https://github.com/dotnet/runtime/pull/128342)).
- Fixed incorrect `madvise()` advice values on Linux ([dotnet/runtime #128605](https://github.com/dotnet/runtime/pull/128605)).
- Fixed a NativeAOT GC hole ([dotnet/runtime #129711](https://github.com/dotnet/runtime/pull/129711)).

#### VM

- Fixed thread-safety in unlocked `MDInternalRW` metadata read methods ([dotnet/runtime #128671](https://github.com/dotnet/runtime/pull/128671)).
- Reduced contention in `UnwindInfoTable` under high-volume LCG method creation ([dotnet/runtime #129035](https://github.com/dotnet/runtime/pull/129035)).

#### Interop / COM

- Fixed a crash when calling a COM interface method on a class whose derived override was created first ([dotnet/runtime #128796](https://github.com/dotnet/runtime/pull/128796)).
- Fixed `UnsafeAccessor` signature for `byref` struct `this` ([dotnet/runtime #128851](https://github.com/dotnet/runtime/pull/128851)).
- Fixed `ComInterfaceGenerator` collision on same-named methods in disjoint cross-assembly bases ([dotnet/runtime #129473](https://github.com/dotnet/runtime/pull/129473)).
- Fixed `TypeLoadException` in `GetMarshalAs` when a `SafeArray` has a zero-length user-defined type name ([dotnet/runtime #129899](https://github.com/dotnet/runtime/pull/129899)).

#### Libraries

- Fixed `ValueType.GetHashCode` for nested generic fields ([dotnet/runtime #129744](https://github.com/dotnet/runtime/pull/129744)).
- Fixed blob type in `CopyWithPrivateKey` for ML-DSA keys ([dotnet/runtime #129865](https://github.com/dotnet/runtime/pull/129865)).
- Fixed thread-safety issue in `DriveInfo.GetDrives()` on macOS by replacing `getmntinfo` with `getfsstat` ([dotnet/runtime #129301](https://github.com/dotnet/runtime/pull/129301)).
- Android: handled `X509ChainContext` creation failures ([dotnet/runtime #128984](https://github.com/dotnet/runtime/pull/128984)).
- Fixed iOS simulator build compatibility with Xcode 26.4 ([dotnet/runtime #128952](https://github.com/dotnet/runtime/pull/128952)).

#### Diagnostics

- Ported dump collection performance improvements ([dotnet/runtime #128023](https://github.com/dotnet/runtime/pull/128023)).
- Added configurable EventPipe CPU sampling rate ([dotnet/runtime #128843](https://github.com/dotnet/runtime/pull/128843)).

#### NativeAOT

- Fixed string GC config handling in NativeAOT ([dotnet/runtime #128894](https://github.com/dotnet/runtime/pull/128894)).

#### Mono AOT

- Fixed Mono AOT typeload error handling ([dotnet/runtime #129804](https://github.com/dotnet/runtime/pull/129804)).
